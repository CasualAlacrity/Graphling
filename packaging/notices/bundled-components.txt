Native components bundled with ALICE
===================================

Python packages carry their license files in their own metadata, and the section above
was generated from those files. The components below are native libraries and model files
that come inside those packages but have no metadata of their own, so they are listed here
by hand. Full texts of the GPL and LGPL licenses are at the end of this file.

Qt 6 (via PySide6 / Shiboken6)
  License: GNU Lesser General Public License v3.0 (LGPL-3.0-only)
  Source:  https://download.qt.io/official_releases/qt/
           https://code.qt.io/cgit/pyside/pyside-setup.git/
  ALICE uses Qt and PySide6 unmodified and links to them dynamically. They ship as
  separate files in the ALICE install folder (Qt6*.dll, PySide6\ and shiboken6\). You
  may replace them with your own compatible build of the same version.

PortAudio (via sounddevice)
  License: MIT (text below)
  Source:  https://github.com/PortAudio/portaudio

Libraries bundled with CTranslate2 (speech recognition engine)
  Intel OpenMP runtime (libiomp5md)   Intel Simplified Software License
                                      https://www.intel.com/content/www/us/en/developer/articles/license/onemkl-license-faq.html

Microsoft Visual C++ Redistributable runtime (via Shiboken6)
  Redistributed under the Microsoft Visual Studio license terms for distributable code.
  https://visualstudio.microsoft.com/license-terms/

Silero VAD voice activity model (via faster-whisper)
  License: MIT (text below)
  Source:  https://github.com/snakers4/silero-vad

Whisper speech recognition model
  Not included in the installer. ALICE downloads it from Hugging Face on first launch
  (Systran/faster-whisper-*, a conversion of OpenAI's Whisper weights).
  License: MIT (text below)
  Source:  https://github.com/openai/whisper
